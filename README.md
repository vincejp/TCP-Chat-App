# Project 2B: Networking Fall 2024

## Usage
To run the server, execute the following command:
```bash
Usage: python3 server.py <host name or ip> <port-num>
```
To run the client, execute the following command:
```bash
Usage: python3 client.py server.py <port-num>

## Register client with server
To register the client with the server, which should be the first step in running the program
```bash
<user_name> <channel_one> <channel_two>, etc
```

## Direct message
To send a direct message to a user, enter @, then the user's name, then a space, and finally, the message you wish to send.
```bash
 @<receiving_user> message
```

## Channel message
To send a message to a channel
```bash
`#<channel> <message>`
